# Proposal — 阶段 10：应用设置与语音转写凭证

> **状态：待实施。** 仅落地设置容器、入口及阿里云凭证管理；不进行音频上传和转写。前置阶段 1～9 的功能均已完成。
>
> **定位**：设置是应用的辅助界面，不是第四个业务主导航；保持 Pata “Less is more / Local First”。

## 一、功能边界

| 场景 | 目标行为 |
|---|---|
| 打开设置 | 通过现有窗口中的可见设置入口进入设置内容；不新开 macOS 窗口；可支持系统常用的 ⌘, 快捷键，但不能只有快捷键 |
| 返回应用 | 返回进入设置前的 Today、Tasks、Notes 或标签视图；遵守已有未保存草稿离开确认 |
| 设置内容 | 「语音转写」分区展示阿里云百炼和 Qwen-Audio 3.1 的只读信息，以及一个 API Key 输入/保存入口 |
| 首次配置 | 输入 `sk-...` 格式的 API Key 并保存至 macOS Keychain；仅在 Keychain 写入成功后显示「已配置」 |
| 再次进入 | 仅展示「已配置」和「更换」；不把既有明文 Key 回显至输入框 |
| 更换密钥 | 由用户主动输入新值并覆盖 Keychain 中对应条目；失败则保留旧密钥 |
| 尚未配置 | 阶段 11 触发转写时提示用户去「语音转写」配置，并能返回原流程 |
| 密钥无效/额度不足 | 保存不代表在线认证成功；由真实转写调用返回可解释的鉴权/额度错误，不新增单独测试连接按钮 |

## 二、交互与布局

- 复用 `frontend/src/App.tsx` 的现有主窗口容器与导航返回机制，可用侧边栏底部小齿轮、已有应用菜单等**辅助入口**；保持 Today / Tasks / Notes 仅三主入口。
- 设置内容最多一组必要配置：「语音转写」标题、服务商/模型只读提示、密码输入框、「保存」/「更换」及「获取 API Key」外部帮助链接。
- 不将地域变成选择器：固定 **阿里云百炼华北 2（北京）**。调用地址及模型 ID 作为内部常量，不暴露自定义端点。
- 保持 Vault/主题现有入口原位；如实现辅助设置入口，不遮挡 Vault 健康提示与当前主题控制。
- 支持键盘焦点、密码输入遮蔽、提示文本；不要在 Toast、日志、错误栈或状态面板里显示明文 Key。

## 三、存储与服务边界

- 提供 App Core 的最小凭证接口，例如「是否已配置 / 设置 Key / 为 ASR 内部调用读取 Key」，而非把 Key 明文塞进 React 全局状态或 Wails 前端持久化。
- macOS Keychain 按固定应用服务名与账户标识存一条密钥；不要与 Vault 根目录绑定。Keychain 写入或读取错误要显式呈现，不能假装已保存。
- 只有真正发送阿里云请求的 Go Core 服务按需读取明文；前端状态只接收是否配置、错误摘要等非敏感信息。系统网络请求不能输出 `Authorization` 头。
- 不在 `.pata/`、`notes/`、`files/` 或 Markdown Frontmatter 中记录 API Key；更换 Vault 不会丢失此项配置。
- 不设多服务商通用 Credential Provider、业务数据库、JSON 侧车或密钥云同步。
- 北京地域调用地址以实现时阿里云官方文档为准；不对用户提供手动改地址的设置。

## 四、实施顺序

### P10-001 — 设置入口与主窗口内容

- 在当前 App 导航架构上增加设置视图及返回行为，不破坏原有导航。
- 实机验证侧边栏底部 Vault 菜单与主题控制完整保留。
- 首次转写缺少配置时的跳转/返回接口为阶段 11 预留，但本阶段不开发音频业务 UI。

### P10-002 — Keychain 凭证能力

- Go Core 实现凭证保存、状态查询、替换及内部读取，错误处理覆盖拒绝访问、写入失败和不存在。
- 前端仅展示遮蔽输入和保存状态，不在消息/日志中泄漏凭证。
- 服务地域北京、模型 `qwen-audio-3.1-asr-flash-filetrans` 为内部固定配置，无环境/地域下拉。

### P10-003 — 安全与原有交互回归

- Go/TypeScript 测试；macOS 实机验证保存、重启后读取、更换及错误提示。
- 验证导航返回、未保存草稿保护、Vault 更换、深浅色主题和现有侧边栏布局均正常。

## 五、验收清单（待实现）

- [ ] 设置可以从当前 App 中用可见入口打开，不新开窗口，不新增一级业务导航。
- [ ] 用户仅需填写 API Key；地域始终北京，模型始终固定，不提供对应选择器。
- [ ] Keychain 保存成功后显示已配置，重启 App 仍可用；密钥更换失败时不破坏旧值。
- [ ] Key 不进入 Vault、前端持久化、日志及 Markdown；前端不能通过“已配置”状态取得现有明文。
- [ ] 未配置 Key 时可由阶段 11 引导进入设置并返回，错误不伪装成成功。
- [ ] Today / Tasks / Notes、Vault 菜单、主题按钮及编辑草稿退出保护无回退。
- [ ] 完成 Go、前端测试和 macOS GUI 实机验收，再进入阶段 11。
