# Idea — 阶段 10：应用设置与语音转写凭证

> **状态：设计已确认，待实施。** 阶段 1～9 的导航、Vault、Notes 和文件资源能力保持不变。本阶段仅交付主窗口内设置入口及后续音频转写所需的凭证能力，不实现转写。

## 为什么要做

目前啪嗒尚无独立的设置内容页：主题切换及 Vault 菜单位于侧边栏底部。阶段 11 的语音转写需要一次性填写阿里云百炼 API Key，但不应每次导入 MP3 都重复配置，也不应为一个 Key 创建完整的云服务管理平台。

## 用户体验

用户从现有应用入口打开**主窗口内**的设置界面，找到「语音转写」，输入一次 API Key 并保存。以后从 Notes 导入录音或重新转写时直接复用已配置密钥。若未配置，从音频创建笔记时引导用户打开该设置项，完成后可返回原流程。

设置仅告诉用户正在使用「阿里云百炼 / Qwen-Audio 3.1」，无需让用户选择服务商、模型或地域。服务地域固定为**华北 2（北京）**。

## 本阶段交付

1. 在现有主窗口中提供轻量设置入口、设置内容页和返回原页面的行为；**不增 Today / Tasks / Notes 之外的主导航**，不打开独立设置窗口。
2. 唯一需要用户输入的配置：阿里云百炼 **API Key**；保存、已配置展示、更换，并妥善处理空值和系统错误。
3. API Key 使用 **macOS Keychain** 保存与读取，不写入 Vault、Markdown、浏览器 LocalStorage、普通配置文件或日志；前端不持久化明文密钥。
4. 北京地域与 `qwen-audio-3.1-asr-flash-filetrans` 模型由应用内部固定；为阶段 11 提供可供 Go Core 调用的凭证读取能力。
5. 与既有主题按钮、Vault 操作、全局搜索、Notes 编辑及未保存内容确认逻辑共存，不以设置功能之名重构现有 UI。

## 明确不做

- 不做地域切换、模型下拉、供应商选择、热词编辑、语言选择、配额/用量面板、连接测试按钮。
- 不做登录账号、云同步、订阅中心、独立配置服务、插件框架。
- 不把现有主题切换或 Vault 管理强行迁移至设置页；这些现有交互保持原样，后续确有需要再讨论。
