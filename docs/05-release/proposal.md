## 标签与全局搜索设计

## 标签

- 全局、平铺、无层级（`Doris`、`Flink`、`架构设计` 等）。
- Task 和 Note 可打标签；独立 Memo 标签可选。
- 任务评论 Memo 在筛选时**动态继承任务当前标签**，不重复写入文件。
- 标签视图按 **任务 / 笔记 / 记录** 纵向分组，不拆列。
- 仅靠相同标签不建立 Task–Note 的显式业务关联。

### 补充优化（已实现）：虚拟「全部」入口

- [x] 侧边栏「全局标签」分组的真实标签之前固定显示「全部」；Vault 已打开时，即使没有真实标签也显示该入口。
- [x] 点击「全部」进入全局标签结果视图，**不按标签过滤**，展示全部 Task、Note、Activity；明确包括没有标签的任务，并沿用现有结果浏览和跳转交互。
- [x] 未选择具体标签而进入全局标签视图时默认「全部」；不改变 App 启动后默认进入 Today 的现有行为。
- [x] 「全部」只是 UI 的虚拟视图入口，不落盘、不计入真实标签数量，不能赋给任务或笔记，也不能重命名或删除；查询时不能把字面值「全部」当作真实标签。
- [x] 切换「全部」与具体标签时不改变其他筛选条件，并遵循现有的未保存内容离开确认行为。

## 搜索

全局快速搜索（⌘K / ⌘P 或侧栏搜索图标），覆盖任务、笔记和草稿的标题与正文，并保留记录和附件结果。任务和笔记还沿用既有标签搜索；附件按名称和路径搜索。Notes 列表提供局部搜索。

### 草稿接入全局搜索（2026-10-21 补充）

- 全局结果按任务、笔记、草稿、记录、附件分组，每组最多显示 5 项并显示该组总数；支持方向键、回车和鼠标打开。草稿按修改时间排序，显示首个非空行标题与正文片段，不按同名笔记推断身份。
- 草稿搜索按不区分大小写的字面子串匹配。每次查询只读扫描 `drafts/`，与列表共用读取及路径校验，外部修改、删除在下一次查询直接可见；不将草稿添加到 Notes 索引或标签聚合。
- `draft` 仅增加搜索结果类型，不是新的 Frontmatter 类型或结构化实体。草稿原文存储格式保持不变。
- 单个无效 UTF-8、符号链接或不可读草稿跳过；草稿目录边界错误明确报告搜索失败，不显示为“未找到结果”。空查询不扫描草稿目录。
- 打开搜索前沿用当前编辑页的保存保护；失败或冲突时保留当前页面。Draft 编辑区支持直接使用 ⌘K / ⌘P，⌘F 仍用于当前草稿查找。
- 搜索结果按草稿 ID 打开当前原文；切换前先完成来源页保存。失效结果不新建草稿、不跳到同名笔记，并显示读取失败。快速切换的旧请求、旧查询及旧 Vault 结果不得覆盖当前页面。
