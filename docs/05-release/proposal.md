# Proposal — 阶段 5：整合查找与稳定交付

## 实施顺序

1. 全局平面标签：点击侧边栏标签，在单列主区域按 Task / Note / Memo 纵向分组。
2. 实现跨类型全文搜索；Memo 关联父 Task 的当前标签以查询时计算为准。
3. 完善索引重建、变更监听、跨编辑器保存冲突、错误报告与回归测试。
4. 打磨快捷键、焦点、基础无障碍、安装打包和首启 Vault 引导。
   - 按 [macOS 原生体验检查项](../01-validate/macos-native.md) 验证原生窗口、菜单、主题、键盘操作、窗口缩放和可访问性。
5. 用真实工作资料走通“早上规划 → 跨天推进 → Memo 留痕 → Note 沉淀 → 历史/标签检索”。

## 标签与全局搜索设计

## 标签

- 全局、平铺、无层级（`Doris`、`Flink`、`架构设计` 等）。
- Task 和 Note 可打标签；独立 Memo 标签可选。
- 任务评论 Memo 在筛选时**动态继承任务当前标签**，不重复写入文件。
- 标签视图按 **任务 / 笔记 / 记录** 纵向分组，不拆列。
- 仅靠相同标签不建立 Task–Note 的显式业务关联。

### 补充优化（已实现）：虚拟「全部」入口

- [x] 侧边栏「全局标签」分组的真实标签之前固定显示「全部」；Vault 已打开时，即使没有真实标签也显示该入口。
- [x] 点击「全部」进入全局标签结果视图，**不按标签过滤**，展示全部 Task、Note、Activity；明确包括没有标签的任务，并沿用现有结果浏览和跳转交互。
- [x] 未选择具体标签而进入全局标签视图时默认「全部」；不改变 App 启动后默认进入 Today 的现有行为。
- [x] 「全部」只是 UI 的虚拟视图入口，不落盘、不计入真实标签数量，不能赋给任务或笔记，也不能重命名或删除；查询时不能把字面值「全部」当作真实标签。
- [x] 切换「全部」与具体标签时不改变其他筛选条件，并遵循现有的未保存内容离开确认行为。

## 搜索

全局快速搜索（可由 ⌘K / ⌘P 打开；最终热键避免冲突），按类型返回结果；覆盖标题、正文、标签及任务关联 Memo。Notes 列表提供局部搜索。

## 数据规则

标签建议以名称字符串存储，归一化空白和大小写策略；不用预建标签实体。标签重命名跨文件批量操作**不纳入 MVP**。

## 不做

标签层级、颜色管理、标签管理页面、复杂条件查询 DSL。
