# Idea — 阶段 6：品牌接入与 Logo 动画

**阶段目的**：承接阶段 5 的 MVP 整合交付，独立完成已选品牌的静态接入与原对话第二步的 Logo 动画。

**目的**：用三层卡片的轻压、回弹和三道光芒，表达「啪嗒」这一瞬间反馈；让启动和记录成功更容易感知，同时保持工作界面安静。

**状态（2026-10-15）**：**代码交付已完成，后续仅做 macOS 实机验收**。V2 标识、图标、启动与保存成功动画、离线预览和静态菜单栏托盘均已接入。菜单栏帧动画与额外悬停动效已明确取消，不再作为待办。详见 [实施笔记](implementation-notes.md) 与 [完成标准](proposal.md#完成标准)。

## 已选定的视觉方向

白色翻折顶层、橙黄色中层、粉紫色底层，右上角三道黄色光芒。使用三层卡片边缘精修 V2，延续圆滑边缘、轻描边和柔和纸张厚度。

原对话早期的蓝紫色羽毛/叶子方向已被用户纠正，后续以本目录 V2 资源为基线。V2 是依据概念图重新绘制的 SVG，不是原概念图的精确矢量原稿。

## 本阶段交付结果

- 静态品牌接入：应用内标识与 macOS 构建图标统一使用三层卡片 V2。
- 应用内启动动画：三层卡片轻微弹出，光芒依次出现，播放一次。
- 交互成功动画：记录真正保存成功后，卡片轻压、回弹，三道光芒短暂亮起。
- 菜单栏：已按后续决策接入**静态单色模板图标 + 点击聚焦主窗口**；不实施点击帧动画。
- 减少动态效果时保留静态标识与原有成功提示；动画不阻塞输入、导航或文件保存。
- 已有可离线查看的动画预览、静态菜单栏模板资源及构建实施记录；macOS 最终实机验收结果待补。

不继续开发鼠标悬停回弹、菜单栏逐帧动画、持续循环、全屏启动等待或动画专属导航；除实机验收发现必须修复的缺陷外，本阶段无新开发事项。

## 与 MVP 的关系

先保证静态品牌资源正确，再加入应用内动画，最后验证菜单栏增强。动画独立于业务闭环，不改变 Task / Memo / Note / DayPlan，也不影响 Today / Tasks / Notes 三导航。

尊重系统主题、强调色和辅助功能。品牌配色只用于标识，不覆盖系统控件强调色。菜单栏新增入口不承担后台驻留、快速捕捉或提醒功能；关窗退出行为保持现有规则。
