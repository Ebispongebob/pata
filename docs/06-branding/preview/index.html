1. 常规尺寸动效展台 (Hero Showcase · 200px)

观察卡片位移、柔和投影同步随动与三道光芒时序
当前状态: 静态基线 (Static)

三层卡片设计以「轻压-回弹」传达「啪嗒」的触觉反馈感，右上角三道光芒呈放射状亮起，保持工作界面安静克制。

  • 投影随动：归档 SVG 原有柔和投影已内嵌至对应卡片内部首位，回弹时投影与卡片绝对同步，无脱节漂移。
  • 光芒独立编组：三道光芒独立标注为 .pata-sparkle-1/2/3，按 1 → 2 → 3 依次绽放/亮起。
  • 防裁切：容器预留安全内边距，SVG 标注 overflow: visible，高斯模糊光晕与边缘位移不被裁切。
  • 保真轮廓：仅施加微量 translateY、scale 与 opacity，绝不畸变精修三次贝塞尔轮廓，无剧烈倾斜旋转。
