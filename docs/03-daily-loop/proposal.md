5. 校验跨天计划、截止日期和历史完成事实彼此独立。

4. 压缩日期栏和空状态，整理单 Vault 全局维护入口，精简计划与时间线展示。保留现有排序按钮；拖拽为后续增强，不阻塞本轮验收。
5. 用真实本地资料走查创建 → 安排 → 编辑 → 完成 → 时间线，并验证历史日期、跨页面同步与失败恢复。

## Today 行为设计

### 页面

顶部为紧凑日期导航，默认今天，包含前后日期切换、日期/星期；浏览其它日期时显示明确的“回到今天”按钮，“今天”状态文字与可点击操作区分。日期栏可从约 48–56px 起调，以实际桌面字号、缩放与可点击区域为准。

区块 A 为有序计划，显示完成数/总数、任务标题、状态、轻量标签和截止标记；区块 B 为倒序时间线，快速 Memo 输入置于时间线上方。空状态使用一两行说明，不单独设置大面积虚线卡片或固定高度；有数据后自然增长。

减少重复卡片边框和大面积强调色，优先用间距、轻分隔线组织内容。遵循 [UI 规范](../01-validate/ui.md) 与 [macOS 原生体验准则](../01-validate/macos-native.md)，内容保持适合阅读，不强制玻璃材质。

单 Vault 路径、重新扫描与健康信息收至现有全局 Vault 入口，例如侧栏底部的折叠菜单；首启无 Vault、扫描失败和冲突提示仍清楚可达。无需新增设置页、多 Vault 或“工作区管理”实体。

### 任务添加

- 输入框提示“添加今天要做的事…”，回车创建并加入当前查看日期；其它日期明确提示“添加当日要做的事…”，不能显示加入今天却写到历史日。
- 保留“从已有任务中选择”的轻量搜索入口；只追加未在该日计划中的任务，不复制 Task，不按 due 自动加入。
- DayPlan 引用任务 ID，任务本身不复制。
- 按钮调整顺序；移出仅取消所查看日期的安排，不删除任务。拖拽可后续增强。
- 未完成任务不自动结转；可提供昨日未完成候选，仍由用户确认添加。

### 时间线

根据 Memo 创建时间和状态事件真实发生时间按日期聚合，倒序展示。每项以时间、内容和轻量图标区分手动记录、任务完成与重新打开；不增加嵌套卡片。显示关联任务并可打开同一详情面板；独立 Memo 无须标题或任务，可编辑原记录。

重新打开任务后，过去的“完成”仍是已发生事实，不删除或改写事件；需要时加注任务当前状态。重扫只读取既有事件，不因页面渲染或扫描生成新的完成记录。

### 历史日期

切换日期展示当日计划与记录，不展示整月日历网格。历史计划数据应稳定，不能因任务后来完成而误认为当时已完成；需要时展示任务当前状态并注明是当前状态。

### 关键约束

Today Plan 不影响 Due；记录时间戳使用本机时区展示，持久化完整 offset 时间。删除任务时必须处理历史 DayPlan 的失效引用（至少保留可解释的占位或确认级联）。

## 共用快速创建与末尾标签

### 输入与解析

Today / Tasks 共用规则：**从输入末尾提取连续、以空白分隔的 `#标签` 词段，其前文本作为任务标题。** 标签名非空，不含空白或 `#`；`#` 必须是独立词段的开头，不能从 `C#` 等词内抽取。移除外部空白，不改写标题中间的原文。

| 输入 | 保存标题 | 保存标签 |
|---|---|---|
| `完成资源管理设计 #工作` | `完成资源管理设计` | 工作 |
| `完成资源管理设计 #工作 #架构` | `完成资源管理设计` | 工作、架构 |
| `完成 #架构 资源管理设计` | `完成 #架构 资源管理设计` | 无 |
| `完成设计 #工作 后续优化` | `完成设计 #工作 后续优化` | 无 |
| `完成 #架构 资源管理设计 #工作` | `完成 #架构 资源管理设计` | 工作 |
| `研究 C# 接口 #技术` | `研究 C# 接口` | 技术 |
| `完成设计 #` | `完成设计 #` | 无；单独 `#` 是未完成词段 |
| `#工作 #架构` | 无 | 提示填写任务名称，不提交 |

标签仅写入现有 `Task.tags`，不带 `#`，相同名称按 [D20](../01-validate/decisions.md) 的大小写不敏感语义去重，保留原始显示形式。新标签随 Task 成功落盘进入全局聚合；“创建标签”不单独写文件，也不预建 Label 实体。此语法只用于快速创建，不扫描任务描述，也不自动解析详情标题。

### 标签建议与键盘

- 光标在输入末尾，以空白后的 `#` 开始标签词段时显示已有全局标签建议；输入名称实时过滤。光标移到中间时关闭，不为中间词段提供标签补全。
- 使用同一全局标签来源，按大小写不敏感匹配；非空且无同名标签时提供“使用新标签「…」”，选择后只是补全输入。
- ↑/↓ 移动候选，Tab/Enter 确认并补一个空格，便于继续输入下一个 `#标签`；有建议时 Enter 优先选中，不能同时创建任务。
- Esc 只关闭建议；弹层关闭后 Enter 才提交。空格结束当前词段；不要求必须选中候选才能保存新标签。
- 中文输入法组合期间，Enter 仅确认文字；空查询没有新标签项，无有效候选时不误提交。

### 创建与失败恢复

任务默认状态为 Todo，无 due；Today 再把新任务 ID 追加到当前日期计划，Tasks 只创建。提交时禁用重复提交；真正成功后更新列表、标签建议与全局聚合。

两步写入分别处理：创建失败保留原输入；Task 已创建、DayPlan 写入失败时明确显示“任务已创建，但未加入计划”，保留该 ID 并提供重新加入或打开任务的操作。重试只保存计划，不再次创建 Task，也不删除已创建文件。

## 共用任务详情与行内操作

### 详情面板

采用类似 ChatGPT 的三栏布局，正常窗口打开详情时三个区域并排：

```text
┌────────────┬───────────────────────┬─────────────────────┐
│ 左侧导航   │ 中间 Today / Tasks    │ 右侧任务详情        │
│ Today      │ 日期、计划、时间线    │ 标题、属性、描述    │
│ Tasks      │ 或全量任务列表        │ Memo、关联 Notes    │
│ Notes      │                       │ 保存、关闭          │
│ 全局标签   │                       │                     │
└────────────┴───────────────────────┴─────────────────────┘
```

Today 点击计划中的任务名称或行空白，按需打开右栏，保留当前导航与日期。中间计划、时间线或 Tasks 列表持续可见、可操作；中间栏与详情栏各自滚动，右栏占用布局空间。Tasks 使用同一详情组件，保留列表上下文。

关闭右栏后，中间内容恢复可用宽度，保留来源位置与焦点。窄窗口先允许收起左导航；空间仍不足时，详情覆盖主区域并提供返回，恢复原页面上下文。三栏用于 Today / Tasks 的任务操作；Notes 仍单列浏览、全主区域编辑。

面板包含现有标题、todo/doing/done、标签、可选 due、纯文本描述（支持换行，不解析 Markdown）、Memo 与显式 Note 关联。标签可在详情内添加/删除，沿用现有编辑能力即可，不新增常驻快速创建标签面板。打开 Note 仍进入全主区域编辑，遵循 Notes 单列规则。

属性和正文表单沿用 [D19](../01-validate/decisions.md) 的手动保存（按钮 / ⌘S）；关闭、切换任务或离开页面时，有草稿则提供保存 / 放弃 / 取消，不能默默丢弃。外部修改仍由现有版本检查拒绝覆盖，提示后人工重新加载；不能因抽取组件丢失冲突保护。

### 行内动作

| 位置 | 行为 | 写入范围 |
|---|---|---|
| 标题、行内空白 | 打开共用详情 | 不写入 |
| 状态图标 | 沿用当前 todo → doing → done → todo 状态切换，提供明确提示 | Task；完成/重开保留既有事件规则 |
| 上下移动按钮 | 调整所查看日期的顺序 | 当日 DayPlan |
| 移出计划 | “移出今日计划”或“移出当日计划”；使用移出图标和文字提示 | 只移除当日 task ID |

行内控件阻止触发打开详情。保存失败保留原显示并提示，可重试。失效任务占位只允许清除计划引用，不能打开空详情；任务永久删除继续由既有 Tasks 删除确认流程承担。

列表状态切换是明确提交的即时动作；详情中的同类字段仍随表单保存。若同一任务有未保存草稿，先完成保存 / 放弃 / 取消选择，再执行行内修改，避免刷新或后续保存覆盖草稿。

### 同步与数据边界

保存后刷新该 Task 的各处引用及受影响的标签、搜索、关联 Memo 结果；关闭面板后计划行显示最新属性，切到 Tasks 也一致，不要求用户重新扫描。UI 可有编辑草稿，不持久化第二份任务。

DayPlan 始终只保存日期和有序 task ID；跨日期引用读取同一 Task。移出不会修改 due、删除 Memo、清空状态事件或改动其它日计划；历史列表展示当前属性时保留“当前状态”注脚。`.pata/plans/` 仍是需备份的业务数据。

## Memo 行为设计

### 最小模型

正文 Markdown、唯一 ID、创建时间、可选 task_id、可选标签。**不需要标题**。

### 写入入口

Today 快速输入 → 独立 Memo；Task 详情输入 → 自动填写 task_id；可补充关联 Task。只有一条源文件。

### 阅读入口

Today 根据创建时间聚合；Task 详情按 task_id 查询；全局标签视图与搜索可查。关联任务 Memo 在标签筛选时继承父任务标签，不强制重复写标签；独立 Memo 可有自有标签。

### 约束

不能把 Memo 自动升级或复制为 Note；需要正式文档时新建 Note 并显式引用原记录。编辑 Memo 保留 created_at，可选 updated_at。

## 不做

独立 Memo 一级导航、长表单、强制归类、附件上传、复杂评论线程；标签实体/管理页、标题中间标签解析、富文本快速创建、任务优先级、新日志实体、统计仪表盘、强制日报、CLI/MCP/AI 集成。拖拽排序可后续增强，Notes 仍独占主区域编辑。
