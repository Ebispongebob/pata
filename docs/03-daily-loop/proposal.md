# Proposal — 阶段 3：跑通每日工作闭环

## 实施顺序

1. Memo 的独立文件创建、读取，以及可选 `task_id` 关联；Task 详情展示评论。
2. DayPlan 的有序 Task ID 保存，Today 可选择已有任务并排序。
3. 今日记录按发生时间汇总独立/关联 Memo 和必要的完成事件，保证同一记录不复制。
4. 历史日期切换；昨日未完成任务仅显示为候选，不自动顺延。
5. 校验跨天计划、截止日期和历史完成事实彼此独立。

## 本阶段完成标准

- [x] 同一 Task 可多日安排而不改变 `due`。（P3-002 服务层测试 + P3-003 独立性测试）
- [x] 任务评论在任务详情和发生当天的 Today 中显示同一源文件。（同一 Memo ID 断言 + 时间线跳转闭环）
- [x] 独立 Memo 没有标题/标签/关联任务也能保存。（P3-001 落盘回读测试）
- [x] 完成任务即使没有 Memo，Today 中也能看到完成事件。（GetDayTimeline completion 项，含完成→重开→再完成多事件）
- [x] 未完成任务不在次日自动堆积，历史日仍能回顾。（昨日候选需确认添加；任意日期计划+时间线可查，历史状态注明当前状态）

## Today 行为设计

## 页面

顶部：日期与前后日期切换，默认今天。区块 A：有序今日任务，显示完成状态、优先级、截止标记。区块 B：按时间倒序的记录，含 Memo 和必要任务事件；底部/顶部可快速输入 Memo。

## 任务添加

- 从 Tasks 选择现有任务；可直接新建任务并加入今天。
- DayPlan 引用任务 ID，任务本身不复制。
- 拖拽或按钮调整顺序，删除仅移出今日计划，不删除任务。
- 未完成任务不自动结转；可提供昨日未完成候选，仍由用户确认添加。

## 时间线

根据记录事件真实发生日期聚合；显示关联任务、可跳转；独立 Memo 无须标题或任务。

## 历史日期

切换日期展示当日计划与记录，不展示整月日历网格。历史计划数据应稳定，不能因任务后来完成而误认为当时已完成；需要时展示任务当前状态并注明是当前状态。

## 关键约束

Today Plan 不影响 Due；记录时间戳使用本机时区展示，持久化完整 offset 时间。删除任务时必须处理历史 DayPlan 的失效引用（至少保留可解释的占位或确认级联）。

## Memo 行为设计

## 最小模型

正文 Markdown、唯一 ID、创建时间、可选 task_id、可选标签。**不需要标题**。

## 写入入口

Today 快速输入 → 独立 Memo；Task 详情输入 → 自动填写 task_id；可补充关联 Task。只有一条源文件。

## 阅读入口

Today 根据创建时间聚合；Task 详情按 task_id 查询；全局标签视图与搜索可查。关联任务 Memo 在标签筛选时继承父任务标签，不强制重复写标签；独立 Memo 可有自有标签。

## 约束

不能把 Memo 自动升级或复制为 Note；需要正式文档时新建 Note 并显式引用原记录。编辑 Memo 保留 created_at，可选 updated_at。

## 不做

独立 Memo 一级导航、长表单、强制归类、附件上传、复杂评论线程。
