# 啪嗒交互原型

本目录是无第三方依赖、双击 `index.html` 即可查看的交互式页面概念验证。

- `index.html`：入口
- `styles.css`：视觉样式
- `app.js`：演示数据及页面交互（刷新重置）
- `screenshots/`：5 个页面状态的 PNG 截图

不提供数据持久化，不连接本地 Markdown Vault，不接入 Vditor，也不模拟 Wails 原生窗口。将它视为设计参考，而非软件实施完成状态。

原生 macOS 27 窗口体验、交通灯和可选 Liquid Glass 的评估清单见 [../macos-native.md](../macos-native.md)。本 HTML 原型中的外观、标题区、色值和截图都**不是原生窗口实现证据**。
