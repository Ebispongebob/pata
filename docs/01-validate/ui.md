## 02 Tasks

统一列表 + 搜索/筛选；点击任务进入同一主区域的 Task 详情，包含属性、Markdown 描述和 Memo 列表。

## 03 Notes 列表

**Flomo 风格单列卡片**：标题 / 两行摘要 / 标签 / 时间，不存在第二层笔记侧栏。

## 04 Notes 编辑

主内容区替换为单篇 Note 编辑（返回按钮、标题、标签、Markdown 编辑区域），左侧仅保留主导航/全局标签。

## 05 全局标签视图

点击 `#Doris`：主区依次排列相关 Tasks → Notes → Memos。关联 Memo 由父任务标签动态匹配。

## 06 全局搜索（交互状态）

快捷键触发轻量弹层，可混合搜索 Task、Note、Memo；最终快捷键方案以真实桌面环境测试为准。

## 视觉设计系统

## 关键词

Flomo 式轻快浏览、**macOS 27 HIG 的原生交互原则**、专注阅读、低干扰、单列优先。具体工程依据与实机验证见 [macOS 原生体验与 Magpie 参考](macos-native.md)。

## 色彩

- 浏览器原型暂用：暖灰白 `#fafaf8`、导航背景 `#f4f4f1`、卡片白 `#fff`。**这些是概念原型的静态色值，不代表实际 macOS 窗口的系统材质。**
- 正文：深石墨 `#242624`；次要文字 `#7b817a`。
- 品牌可用低饱和森林绿 `#47715a`；**系统导航选中态、焦点和常规控件优先尊重用户系统强调色**，不强制全部绿色；危险操作需要文字/图标双重提示。
- 标签呈轻量文本/淡底胶囊，不上强彩虹色。

## 版式

- 左侧栏默认可参考 200–240px，但**不是不可收起的固定宽度**；应随窗口尺寸适配；主内容最大宽 900px，居中或适度左对齐。
- Notes 卡片列表正文约 700–760px，始终一列。
- Note 编辑器正文尽量在 740–820px 内，提高长文阅读舒适度；**编辑区独占主区域**而不是 UI 意义上的新增列。
- 遵守 8px 间距节奏；可点击目标尽量不低于 32–36px。
- 小屏时侧栏可收起，不强制三列缩放。

## 交互

- 点击卡片进入详情，返回保留列表筛选。
- Today 项目可完成、排序、移出；独立 Memo 无标题快速录入。
- 任务详情可直接追加 Memo，Notes 编辑页可全文工作。
- 键盘快捷搜索、焦点态、无障碍对比度需要在真实 UI 中验证。
- 原生窗口交通灯、标题栏拖动/no-drag、macOS 全屏/窗口缩放、系统深浅色/强调色/减少透明度等，按 [macos-native.md](macos-native.md) 验证。
- 视觉材质用于导航和控件而非内容层；不要仅靠 CSS 画红黄绿按钮冒充系统窗口。

## 反模式

不使用高密度仪表盘、卡片内嵌多层表单、三列编辑器、固定占屏的标签树、复杂统计/热力图，也不使用全区域玻璃化、持续动效或网页伪装的 macOS 系统控件。
